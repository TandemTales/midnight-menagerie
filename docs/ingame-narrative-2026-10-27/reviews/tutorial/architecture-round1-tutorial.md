# Architecture review round 1 from tutorial editor

Reviewer role: separate AI agent; onboarding, accessibility and adversarial player reading. This is a manuscript/source review, not child testing. Reviewed the current 02 narrative bible without a prior score or writer defense.

1. **High — opening paragraph “At the Heart the child meets the pet before facing the rule.”** This fixes a pet encounter into every Heart visit, even though N.pet may already be home and a six-wing run need not have completed a personal investigation. A repeat player could be told the pet is captive again. Specify unknown/found/home branches and the minimum reliable evidence sequence for the unknown branch; home must use a resident animal or stored memory without recapture.
2. **High — revelation E “Winning means taking everything away.”** This is an authored belief assigned to the player. A child who already wants to help could experience the story lecturing them for an opinion they never held. Recast all initial-belief column entries as possible questions or House claims; explicitly never speak them as the player's belief.
3. **Medium — global state contract writes “seen/evidence only after content is delivered.”** Skipping to recap is not yet precise about whether scene-seen and clue-found are different. Mark a unit seen when its recap actually delivers its core event; mark only the clue IDs quoted in that recap as found. Otherwise implementation can either endlessly repeat skipped scenes or silently credit unseen optional evidence.
4. **Medium — “A co-op choice is labeled a party decision.”** Actual map voting can resolve to an option some players opposed. Label it the selected route/result, not group consent or a unanimous decision. The surrounding contract already rejects invented emotional choices; make this consistent.
5. **Medium — inherited optional trigger.** Essential intro/Heart units need explicit exceptions at their definitions. “Optional unless labeled essential” risks a programmer dropping the only clue after a skipped cutscene. Require an essential-carrier manifest mapping each mandatory fact to one forced, brief screen at the current route.
6. **Low — INTRO repetition.** Intro and proposed opening repeat the same pet anecdotes. Use INTRO only in selection/help or opening, not automatically both in one session; root's scene scheduler should suppress the duplicate.

Strengths: animal behavior communicates choice without menus pretending to translate animals; canonical age drift is acknowledged; no cure plot; captions avoid animation requirements; guardian comic motivations are distinct. The requested reading budget and reduced-motion fallback are plausible but unverified in the UI.
