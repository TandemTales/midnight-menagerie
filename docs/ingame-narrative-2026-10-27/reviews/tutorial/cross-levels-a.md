# Independent cross review of levels 01 through 08

Reviewer: tutorial agent, independent of these level drafts and their writer's defense/scores. Read all eight v1 packages. Roles: accessibility, child onboarding, adversarial sequence, narrative pacing. Manuscript review only; no playtest or runtime validation.

1. **High — L06-B, Mateo conditional.** Mateo asks about the WENT HOME names whether or not C2 was seen, but the fallback that places a plaque in view runs only when Mateo is absent. A Mateo player skipping C2 knows something they never encountered. Put the plaque description before the speaker branch for everyone, or gate the question on actual C2 delivery and supply a direct-observation question otherwise.
2. **High — L00-REPEAT and global P rules.** Repeats are handled for boss entry but not explicitly for P completion. Does a repeat win replay the same conversion or show the original P recap stating “has begun” each time? Define repeated P output and clarify that any “room reset” is a provisional explanation, never a pet recapture. Best stateless fallback is a current-tense observation of the local change, not a lasting personality conversion.
3. **Medium — all eight P recaps.** Seven explain versions of the same moral at the end of the same scene shape. Local consequences are distinctive enough, but the recap layer erases that distinction into a recurring lesson. Keep each recap's concrete event first; only a few need an explicit general moral. Example L05: “The Conservatory stopped closing the gap in its canopy. There is a way out of this shelter.” The Heart can assemble the larger inference.
4. **Medium — display estimate contradiction.** Final reading budget assumes 180 words/minute while root bible assumes 100–120 and intended players are 7–10. Unify conservatively around 100–120 for planning; 60–100 word P scenes need about 30–60 seconds, plus optional consideration, not universally 20–35. All still manual advance, so this is a pacing estimate defect rather than a timed-read hazard.
5. **Medium — L05-C2 pressed leaf.** A pressed leaf labeled as leaving and returning is not self-explanatory evidence of the same living being returning: a reader may imagine a seasonal replacement leaf or a dead leaf on a draft. The question concerns return, so depict a clearly recognizable mobile supernatural plant in two records, or deliberately make this a weak clue and reserve the inference for L06/L07. No need to invent named founder/history.
6. **Low — L03-P recap.** “Returned control ... to the creature using it” implies an occupant is present, but no creature is shown in the scene. Say “The curtain can now be opened from underneath” and let optional occupant behavior carry the inference if added.
7. **Low — L07-BT2.** “Alphabetize my feelings later” sounds like generic contemporary quip rather than this bureaucratic character's precise comic business. A concrete label gag would be more distinctive, e.g. “Upset. Very upset. I shall need a divider.” Preserve actual Final Edition notice.

What works: the plain spoon, duster hat, enormous bed hiding its own feet and tilted-table prophecy are strong visual comedy with caption-only feasibility. The Graveyard explicitly distinguishes memorials from missing-pet evidence. Mechanical notes do not pretend barks are guaranteed subtitles. Boss consequences are more specific than opening generic doors.

Diagnostic package score: character 13/15, humor 17/20, tutorial/information delivery 12/15, mystery 13/15, agency 13/15, pacing/replay 7/10, canon/state 4/5, age/readability 4/5 = **83/100**. Several issues are small individually; repeated scene shape and replay state need substantive attention. These scores are this reviewer's judgment, not a measurement or child response.
