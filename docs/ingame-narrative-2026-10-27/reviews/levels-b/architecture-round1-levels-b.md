# Architecture review round one from the late region writer

Review target: `02-narrative-character-bible.md`, version read before root's first revision. This is an independent agent critique, not a playtest. The reviewer also writes late-region scripts and therefore is not blind to the whole assignment. No prior score or author defence was supplied.

## Findings

1. **High — The playable story, “At the Heart the child meets the pet before facing the rule that keeps them apart.”** This is unconditional even though the same document marks pet support proposed and the live game's Heart is reachable without a completed investigation. It can cause the implementation to spawn every selected pet at every Heart. Specify an eligibility contract and a no-pet branch; describe the desired supported path conditionally. A child must not claim prior recognition when no personal evidence or sighting has been shown.

2. **High — N state namespace, “Persistent per local profile; multiplayer ownership unresolved until integration.”** The document is meant to let writers avoid contradictions now. Leaving ownership undefined means the same boss scene can count a pet as home for one player and missing for another. Require per-profile pet facts, party-shared presentation only for facts visibly shown to all, no implicit writes to absent profiles, and conservative neutral text on mismatched clients. Mark actual synchronization engineering unresolved.

3. **High — Repeat contract has no post-sanctuary combat meaning.** “First eligible unseen scene” is inadequate if the House has genuinely changed and later runs still contain the same locking guardians. Define a clearly opted-in remembered-expedition wrapper after sanctuary, or defer canonical sanctuary status in a build unable to frame replay. Never silently relock pets or erase the ending.

4. **Medium — Choice beat, “Some residents approach the exit, another settles inside beside an open door.”** A settled animal is not enough to prove an available exit if the last scene showed outside-only handles. Require the script to show an animal traverse the threshold and return, then a different animal elect to remain with the exit still usable. Root's ending may already plan this; make it a binding architecture test.

5. **Medium — Character intro repeat rule, “quoted last line only.”** For INTRO-MATEO the last speech is “I want to hear him again”; after Pepper is home this becomes misleading. For INTRO-JORDAN it is “I hope someone is helping him,” equally wrong after rescue. Suppress search intros when N.pet=home and provide exact post-reunion dossier alternates, or constrain these records to missing-pet profiles.

6. **Medium — Comedy motif list drifts from source identities.** Harvest King “abundance” could accidentally duplicate the Conservatory and Confectioner; its established distinction is deciding the proper timing of growth. Kennelmaster “assignments” overlaps Scout's personal exploitation but misses its wider demand for guaranteed safety. Lamplighter “reassurance” misses hoarding/control of light. Re-anchor those three terms to the source before writers converge on generic helpful-but-wrong dialogue.

7. **Low — The playable story lists “which safe question to ask” as player authorship without a question-choice dependency.** Either point to exact supported/proposed dialogue choices or say optional examination. Merely continuing a scripted child question is not choosing it.

## Structure-first recommendation

Fix pet eligibility, profile ownership and post-ending replay before line polish. Preserve the core distinction that new supernatural forms can remain loved. The source does not support a founder reveal; keeping that absent is correct. The animals' behavioral language is a stronger foundation than having them explain the theme aloud.

No numeric whole-game score: the complete integrated writing was not available to this reviewer at this point. Category scoring now would reward promised work.
