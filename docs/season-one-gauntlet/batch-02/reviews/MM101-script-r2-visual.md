## Remaining actual fixes

### SV2-01 — Medium, S08/S09/S10 versus S11: normalize the single trolley's load history

S08 still calls it an **“empty bed trolley piled high”**. S09 says the Giant is busy unfolding frames; S10 refers to already laid-out empty beds; S11 now explicitly counts seven **folded** frames/mattresses aboard after choosing the tiny eighth bed. This can be drawn, but the script currently leaves the board artist to decide which beds were unloaded/reloaded.

**Minimal fix:** Call the trolley unoccupied, loaded with eight folded beds. In S09 let the Giant check, number or compare the folded frames without unloading them. In S10 put the Do Not Disturb cards beside the intended bed positions or on the stack, instead of implying all beds have already been laid out. Retain the exact seven-bed load in S11. This is one consistent state choice, not a new action beat.

### SV2-02 — Low, S11: specify Maya's support during the brake action

The script now says she presses and raises the pedal correctly, then “takes both crutches” when finished. It never says where those crutches went during this scene. That phrase can accidentally suggest unsupported standing while operating a floor pedal; the earlier Coat Room had a clearly fixed bench-side support, but this is another room and a moving trolley.

**Minimal fix:** Keep both forearm crutches with Maya throughout the scene and specify pedal operation from a stable stance on the clear side, with the release accessible without leaning on the moving trolley; remove the later implication that both crutches were set aside. Alternatively establish a fixed supported position and reachable control deliberately. This is a blocking clarification, not an assertion that a crutch user cannot operate a brake.
