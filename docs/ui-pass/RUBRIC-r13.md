# Blind style judgment — rubric, round 13: CHROME, SECOND PASS

Read `RUBRIC.md`, then `RUBRIC-r1.md` for its EXPAND section, then
`RUBRIC-r12.md` in full: what the three screens are, the three readability
failures a still can show (a veil the board shows through, a coach note over
what it teaches, a toast on the HUD), and how the dimensions read on pieces
this small. All of it holds. This file wins where they disagree.

**What changed since round 12.** The coach, the veil and the toast are no
longer web chrome in any candidate: every one of them, the baseline
included, is built from the game's own kit. So the question is no longer
"does this belong to the painted world" but **"could this sit beside the
samples"** — the filigree, the double rules, the engraved type, the painted
light. Score against the samples, not against round 12's web versions; a
candidate that only matches the baseline has not improved it.

Things round 12's judges all named, and which should count against a piece
wherever you still see them:

- a spotlight that reads as a SELECTION BOX (a hard rectangle drawn over the
  room) rather than as light falling on the thing it names;
- a note with nothing linking it to what it points at;
- portraits that sit on the veil's painting like pasted cards, with no frame
  worth the name and no backing;
- the same name or line written twice on one screen;
- a toast whose plate is a plain dark bar, or which sits on the room's own
  dressing (a candle sconce) rather than in open wall.

`fits_between_samples` keeps its meaning.
