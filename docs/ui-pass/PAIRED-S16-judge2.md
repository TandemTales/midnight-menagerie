### PATTERN
The rooms differ in only four wings (study, nursery, kitchens, ballroom), and each time the better version keeps the near floor lit to the foot of the frame; the worse one lets the front third fall toward black. The other thirteen rooms are pixel-identical. On the screens, almost every difference is where help/Discoveries lives. The labelled plate itself is well drawn, so the loss is about where it sits, not how it looks. Next, the better versions most need: (1) a consistent lit near floor in every wing, so no room's foreground goes dark; (2) a help home that never covers corner dressing or other plates, with the clubhouse's note cards kept off the map card's wing count; (3) the samples' level of painted ground under the HUD, since the boards still read as dark panels laid on a room rather than one painted scene.
