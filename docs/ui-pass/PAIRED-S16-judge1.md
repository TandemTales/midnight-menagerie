### PATTERN
Almost every screen difference comes down to where "Discoveries / How to play" lives. The better version uses two small round enamel medallions on the left gold frame. The worse one uses labelled plaques that cover a candle (map, atlas, hud-late), float over the fight floor (combat), or sit on the carpet (rest). The one exception is the clubhouse board, where the decider is a note card covering the "1" of "1 / 17 WINGS". In the four rooms that differ, the better version lights the near floor so objects stand on boards, rugs and flags that reach the frame edge; the worse version lets the bottom third fall to black. To get closer to the samples, the better versions most need:
1. The same near-floor lamp in every room, so no foreground falls to black.
2. The help medallions drawn as real filigree cartouches with tooltips or plates, so the bare medallions read as controls.
3. Combat status floaters and pinned board notes drawn as framed objects that never sit over a candle, a label or a number.
