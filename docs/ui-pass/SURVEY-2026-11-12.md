## The clubhouse loss is a browser paint bug, not a change in the game

No code that draws the clubhouse changed between surveys 16 and 17, and survey 16's own build loses the headline today too. The headline is in the DOM, visible, styled and set in a loaded face, and the hit test finds it on top.

- **The trigger:** Chrome 157.0.8103.78 does not paint the headline at `z-index: auto` inside the cutting's rotated, drop-shadowed paper.
- **Ruled out by toggling live:** weight, shadow, display and wrapping.
- **The fix:** `z-index: 1` on `.kit-newscutting__head` restores it on every load. That is repair 18.
