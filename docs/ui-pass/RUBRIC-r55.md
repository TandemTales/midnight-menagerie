neutral candidate in the supplied order. Images only: no source, notes, metadata,
tests, identities, prior scores or other reviews. Score every dimension for each

removed information. Below-viewport content alone does not imply inaccessibility;
unexplained clipping, broad dissolves and detached boundaries remain visual faults.

prescribe constant opacity or changed lifetimes from one frozen phase. Make no
interaction claims from stills. Ignore preview banners and unchanged combat room,
