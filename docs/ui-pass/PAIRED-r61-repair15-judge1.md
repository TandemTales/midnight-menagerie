### PATTERN
The two versions are otherwise pixel-identical (top bar, map, hand, boss, rooms); the only difference is how the focused help control on the left frame rail is drawn. The better version keeps the focused control an object -- a brass-rimmed enamel "?" medallion with a framed plaque beside it, the samples' round-button-plus-cartouche language -- so a pad player sees a lit piece of furniture. The worse version swaps that for a hard rectangular yellow outline with no medallion, which is exactly the flat web-box look the rubric penalises, and it also loses the "?" glyph that tells the player what the control is. Even in the better version the focus cue is subtle (the gold ring barely differs from the unfocused state), the plaque at 1280 overlaps the map's "THE WAY IN" lettering, and the rail control is still smaller and plainer than the samples' large gold-rimmed purple enamel buttons with filigree surrounds.
