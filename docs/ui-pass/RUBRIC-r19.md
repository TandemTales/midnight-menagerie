# Blind style judgment — rubric, round 19: THE BOARDS AND THE CONTROLS

Read `RUBRIC.md` first for the 0-10 scale, the eight fields and the blindness
rules; this file wins where they disagree. Two standing rulings from the
game's owner hold on every screen: a screen's COLOUR is not held to the
samples' hues — what matters is readable, accurately drawn, well-detailed
objects — and the darks are where this house keeps its colour, so a pale,
milky or grey dark is a defect, not a fix.

**Nine screens**: the six boards between fights (`shop`, `reward`, `event`,
`map`, `rest`, `gameover`), two dialogs (`settings`, `piles`) and one fight
with a full hand (`combat-crowd`). Every screen has a 1280x800 capture, and
this round **1280 is not only for readability**: 1280x800 is the Steam Deck,
the platform the game ships on first, so a layout that breaks at 1280 is a
defect of the screen, scored in `composition` and `readability`.

## WHAT THIS ROUND IS FOR, so you know what to look at first

A survey before this round found the same defects shared across many screens.
Look for each on every screen where it could appear:

1. **The run HUD strip.** Does it hold ONE row at 1280, legible, clear of
   everything under it? Two rows at 1280 is a failure on every screen that
   has it.
2. **The board wall.** Picture frames around empty black rectangles read as
   holes in the wall, and a window drawn over a picture frame is a
   construction error a viewer can name. Is every frame on the wall either a
   picture or gone?
3. **The controls.** Toggles, sliders, selects, search fields, item icons,
   pills, steppers and small arrow buttons: do they read as objects from this
   house — brass, enamel, engraved plates — or as web form elements painted
   gold? Is it ONE vocabulary across the screens, or a different invention on
   each?
4. **The map's routes.** Can you trace which room leads to which? Continuous
   lines, rim to rim, no crossings, the next steps distinguishable from the
   rest.

## WHAT IS NOT A DIFFERENCE ANY BUILDER MADE — do not score it

- **The room behind the fight** on `combat-crowd` (its pixel stair-stepping,
  the floor under the Kid). Not this round's work; score the HUD, the hand and
  the board over it.
- **Painted assets**: Mr. Moth's portrait, the card art, the Kids and the
  Companions. They are the same painting in every candidate.
- **A "PREVIEW" or "STANDALONE PREVIEW" plate** on a board: it is what a
  screen shows when a harness opens it outside a run, identical in every
  candidate. Ignore it.
- **Arrangement** that the game deals by seed.

## `fits_between_samples`

Would a viewer believe this screen was painted by the same hand as the four
samples? No screen in this game has earned it outside the room sheets. Say
plainly which object costs a screen its TRUE.

## `worst_problem`

Name the screen, the object and where it is, and say what is wrong with it.
"The five filter controls under the title are rounded selects with chevron
circles, a web filter bar" is useful. "It looks like UI" tells a builder
nothing.
