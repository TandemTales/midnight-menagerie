# The survey, 2026-10-12 — after rounds 27-30

Rounds 27-30 and their grafts did survey 3's list: the card (+1.62), the props
and darks (+2.39), four more rooms (+1.75), the run strip and the parchment
(+2.72). The whole game was photographed again at the Steam Deck's tier
(`survey-2026-10-12.sh` from `59e49cd2`, into `C:/UILOOP/survey4/NOW/`), and
two blind judges scored it in opposite orders (`SURVEY4-judge-prompt.md`;
`C:/UILOOP/survey4/judge1.md`, `judge2.md`, and for the rooms
`judge1-rooms.md`, `judge2-rooms.md`).

**THE ROOMS WERE PHOTOGRAPHED TWICE, AND THE FIRST SET WAS WRONG.** The survey
script (and survey 3's before it) ran `room_batch --regions all` with no seed,
which draws each wing's bare BASE SHELL -- a room no player ever sees, because
a fight always passes its room's name as the seed and every wing maps a name
onto one of its BUILT rooms (`ROOM_KINDS`). Both judges duly reported beds,
beams and far walls "missing" that rounds 28-29 had built. The script now
seeds each wing's main room (the rounds' sheet seeds); the rooms were
re-photographed and re-judged. The first set is kept in
`NOW/rooms-unseeded/` and must not be used. **Survey 3's room scores carry
the same flaw.**

   50-60% of the frame as undressed floor fading to black" (J2); "the light
   and dressing stop at the far wall, leaving the near floor as an unlit or
   black void" (J1). Nursery, passages, pumpkin, attic, study, kitchens,
